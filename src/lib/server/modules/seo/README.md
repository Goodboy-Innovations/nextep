# seo

Search visibility is the main promise to organizations, so it is its own module.

- `eventJsonLd()` — schema.org `Event` JSON-LD for event pages (Google event listings).
- `sitemapXml()` — `/sitemap.xml` from verified organizations and published events.
- `absoluteUrl()` — canonical URLs from `ORIGIN`.

Next: redirects from old slugs when an organization or event is renamed.
